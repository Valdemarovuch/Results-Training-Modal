# 📊 YOLOv11: PFM-1 Mine Detection Results

Цей репозиторій містить виключно результати навчання нейронної мережі YOLOv11 (Anchor-Free) для задачі детекції малогабаритних вибухонебезпечних предметів — мін ПФМ-1 («Пелюстка»).

## 📌 Деталі експерименту
- **Архітектура:** YOLOv11 (PyTorch)
- **Розмір датасету:** 10 000 - 13 000 зображень
- **Кількість епох (Epochs):** 300
- **Гіперпараметри Loss-функції:** Box Loss = 15.0, Cls Loss = 0.5
- **Оптимізатор:** AdamW (lr=0.0001)

## 🏆 Фінальні метрики моделі
Після 300 епох були досягнуті наступні результати:
* **Precision:** 98.85%
* **Recall:** 96.26%
* **mAP@0.5:** 99.19%
* **mAP@0.5:0.95:** 89.43%

## 📂 Вміст репозиторію
Усі ключові графіки та таблиці згенеровані автоматично під час валідації моделі:

1. `results.csv` — покрокові значення всіх метрик для кожної епохи навчання.
2. `results.png` — загальний візуальний графік динаміки навчання (функції втрат та точності).
3. `confusion_matrix.png` — матриця помилок.
4. `val_batch0_pred.jpg` — візуальний приклад предикту (детекції) моделі на валідаційному батчі.
5. `train_batch0.jpg` — приклад розширеної аугментації даних (Mosaic, Mixup), на якій навчалася модель.
